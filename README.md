# Planner

주간 플래너 맥 앱 (Tauri 2)

## 기능
- **빠른 추가** (`⌘K`): 한 줄로 입력 → Enter. `⌘Enter`는 편집 창에서 이어서 수정
  - `수 19시 운영진 회의 @7호관` · `내일 3시 멘토링` · `다음주 화 오후 2시 반 면담 1시간`
  - `10/20 캡스톤 제출 마감` (마감/제출 → D-day) · `!발표 리허설 목`
  - `매주 목 20:00-22:00 스터디` · `격주 월 10시 1:1` · `매월 첫째 금 18시 총회`
  - 오전/오후 없이 1~7시는 오후로 인식
- **실행 취소** `⌘Z` / 다시 실행 `⌘⇧Z` (최대 50단계)
- **메모 → 할 일**: 메모에 `- [ ] 발표자료 수정 금` 처럼 쓰면 할 일로 등록 (날짜 쓰면 그 날), `[x]` 면 완료
- **마감 · D-day**: 일정에 ⚑ 마감 체크 → 상단에 D-day, 전날·당일 09:00 알림
- **주 / 월 / 년 보기**: `w` `m` `y`, ← → 이동, `t` 오늘
- **주간 시간표**: 주간 보기에서 `목록 / 시간표` 전환 (주간 보기에서 `w`)
  - 빈 칸 클릭 → 그 시각에 새 일정, 블록 드래그 → 날짜·시간 이동, 아래 가장자리 드래그 → 길이 조절
- **여러 날 일정**: 종료 날짜 지정, 빠른 추가 `10/2~4 해커톤`, `10월 30일~11월 2일 학회`
- **주간 돌아보기** (`v`, ◔): 회의 수, 준비·할 일 완료율, 남은 할 일 다음 주로 옮기기. 일요일 21:00 알림
- **회의록 모아보기**: 정기 회의 관리(↻) 또는 회차 편집 창의 "회의록" → 회차별 메모 한눈에, Markdown 저장
- **테마**: 설정에서 시스템 / 라이트 / 다크
- **데이터 위치**: 설정에서 이 맥 / iCloud Drive (`iCloud Drive/Planner/planner.json`)
- **정기 회의** (`r`): 매주 · 격주 · 매월 n번째(마지막) 요일
  - 회차별 메모, 이번 회차만 건너뛰기, "정기 회의 관리"에서 전체 목록
  - 회차에서 수정/삭제할 때 범위 선택: 이 회차만 · 이후 회차 모두 · 전체 회차
- **일정** (`n`): 메모 가능, 날짜 칸의 + 로도 추가. 시간은 24시간제로 입력 (`13`, `1330`, `13:30`)
- **준비 체크리스트**: 일정마다 준비할 것 체크. 정기 회의·카드에는 매번 자동으로 들어갈 기본 항목
- **카드 보관함** (`c`): 자주 쓰는 일정을 카드로 저장 → 날짜로 드래그. 정기 회의 카드는 끌면 한 번 더 추가
- **시간 겹침 경고**: 같은 날 시간이 겹치면 ⚠ 표시
- **드래그로 옮기기**: 일정/할 일을 다른 날로 끌어다 놓기 (정기 회의는 그 회차만 이동), ⌥ 누르고 끌면 복사
- **할 일**: 날짜별 체크리스트, 오늘 칸의 "밀린 할 일 가져오기"
- **검색** (`⌘F` 또는 `/`): 제목, 장소, 회의 메모, 할 일
- **알림**: 시작 n분 전 맥 알림 (⚙︎ 설정)
- **메뉴바**: 아이콘 클릭 → 오늘/내일 미니 창, 우클릭 → 열기/종료
  - 창을 닫아도 메뉴바에서 계속 실행 (알림 유지). 완전히 끄기: ⌘Q
  - 설정에서 "로그인 시 자동 실행" (빌드한 앱에서 켜기)
- **백업**: 매일 자동 백업 14일치 + JSON 백업/가져오기 + 캘린더(.ics) 내보내기

데이터: `~/Library/Application Support/com.jiin.planner/planner.json` (자동 백업은 `backups/`)

## 실행 / 빌드
```bash
npm install
npm run dev      # 개발 모드
npm run build    # → src-tauri/target/release/bundle/macos/Planner.app
```
처음 열 때 막히면 Finder에서 우클릭 → 열기 (또는 `xattr -cr /Applications/Planner.app`)
